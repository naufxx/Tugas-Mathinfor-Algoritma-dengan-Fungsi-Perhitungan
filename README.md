Program untuk mengelompokkan usia berdasarkan kategori usia dari Departemen Kesehatan dan BPS dengan klasifikasi sebagai berikut:

**Departemen Kesehatan:**
- <5 Tahun: Bayi dan Balita
- 5–9 Tahun: Anak-anak
- 10–18 Tahun: Remaja
- 18–59 Tahun: Dewasa
- 60+ Tahun: Lansia

**BPS:**
- 0–14 Tahun: Belum Produktif
- 15–64 Tahun: Produktif
- 65+ Tahun: Tidak Produktif
